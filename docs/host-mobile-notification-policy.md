# Host notification policy foundation

Audit: 16 October 2026, backend main 452edef8beea3f6ef5d6c280ec857aecab2c369f. No mobile push registration/provider implementation was found in the recursive repository source inventory or audited Host dependency/configuration files. Existing guest-incident host notification code sends email; it is not mobile push.

The pure prepareHostAttentionNotification policy prepares metadata only for opted-in current Host recipients with an active session and access to the event organization/property. It skips resolved/waiting/autonomous events, stale or future signals and invalid settings. It defers during local quiet hours; a critical bypass requires explicit preference. Payloads are generic English pointers and omit source text, guest identity, access codes and private notes. Stable actor/event deduplication keys require a future durable unique constraint at dispatch.

This policy has no runtime caller and sends nothing. It is not a notification delivery feature. Required implementation: authenticated device registration and session/logout/revocation cleanup; per-user preferences UI and persistence; durable scoped event/device outbox with unique identity, current-state/role/property rechecks, leases and delivery/receipt tracking; provider credentials and invalid-token retirement; app permission UX and cold/warm/background handling with freshly authorized navigation. Access target remains reserved until a reviewed native access destination exists; do not activate it before then. Unknown provider outcomes must not be treated as delivered or blindly retried. Denied notification permission leaves in-app Mission Control usable. Existing email/SMS rules are unchanged.

Validation: six synthetic local policy tests passed (privacy, permissions/opt-out, inactive/stale signals, quiet hours, invalid configuration, dedupe identity); TypeScript passed. The foundation workflow includes these tests and typecheck. No device token, provider credential, production setting, real notification, database schema or delivery worker was created or changed.
